# Domain Glossary

<!-- lang:en -->

What the words mean in this repo. Use these terms exactly — in issue titles, test names, PR bodies.

| Term | Definition | Aliases to avoid |
|---|---|---|
| **Agentic Framework** | the umbrella: the site and the team's agent-first ecosystem it presents | "the project", "our framework" |
| **ecosystem** | the presented projects: **xeno-skills** (hub), **openclink**, **clone space** | "products", "tools" |
| **xeno-skills** | agent skills + enforcement hooks + the T4 operating standard (`xenodeve/xeno-skills`) — the hub of the site | "the skills repo" |
| **openclink** | the MCP transport the `clink-*` skills use for multi-agent orchestration (`xenodeve/openclink`) | "the MCP", "pal-mcp" |
| **clone space** | machine-readable web archives the design-family skills use as reference (`xenodeve/clone-space-mcp`) | "the archiver" |
| **operating standard** | the T4 rule set a repo runs agent-primary on (skills, hooks, memory, gates) | "the standard" alone |
| **content stub** | a `content/` page explicitly awaiting distilled source data — marked as a stub | "draft" (a draft is in-progress work; a stub waits on input) |
| **deep-dive** | a page or post distilled from a source analysis in `docs/` | "article" (any post is a post; a deep-dive has a source doc) |
| **hub-and-spoke** | the draft IA: xeno-skills is the core; openclink and clone space are tools it calls | "three equal projects" |

A concept missing from this table is a signal: either you are inventing language, or there is a real gap.

`CONTEXT.md` / `UBIQUITOUS_LANGUAGE.md` are created lazily when a term or decision actually resolves (proceed silently until then).

คำแต่ละคำใน repo นี้ยืนยงว่าอะไร ใช้คำเหล่านี้ตรงตัว — ในชื่อ issue, test name, PR body

| คำ | นิยาม | alias ที่เลี่ยง |
|---|---|---|
| **Agentic Framework** | ร่มใหญ่: เว็บ + ecosystem agent-first ของทีมที่เว็บนี้ present | "โปรเจกต์", "framework เรา" |
| **ecosystem** | โปรเจกต์ที่ถูก present: **xeno-skills** (hub), **openclink**, **clone space** | "products", "tools" |
| **xeno-skills** | agent skills + enforcement hooks + มาตรฐาน T4 (`xenodeve/xeno-skills`) — แกนกลางของเว็บ | "repo skills" |
| **openclink** | MCP transport ที่ skill ตระกูล `clink-*` เรียกใช้สำหรับ multi-agent orchestration (`xenodeve/openclink`) | "the MCP", "pal-mcp" |
| **clone space** | เว็บ archive ที่ agent อ่านได้ สำหรับให้ design-family skills ใช้เป็น reference (`xenodeve/clone-space-mcp`) | "the archiver" |
| **operating standard** | ชุดกฎ T4 ที่ repo ทำงานแบบ agent-primary (skills, hooks, memory, gates) | "มาตรฐาน" ล้วนๆ |
| **content stub** | หน้า `content/` ที่ประกาศชัดว่ารอ source data ที่ยังไม่ถูก distill — ติดป้าย stub | "draft" (draft คืองานที่กำลังทำ; stub คือรอ input) |
| **deep-dive** | หน้าหรือโพสต์ที่ distill จาก source analysis ใน `docs/` | "article" (โพสต์ไหนก็ได้คือโพสต์; deep-dive มี source doc) |
| **hub-and-spoke** | IA ตาม spec draft: xeno-skills เป็นแกน · openclink และ clone space เป็นเครื่องมือที่มันเรียก | "สามโปรเจกต์เท่ากัน" |

concept ที่ไม่มีในตารางคือสัญญาณ: หรือกำลังประดิษฐ์คำ หรือมีช่องว่างจริง

`CONTEXT.md` / `UBIQUITOUS_LANGUAGE.md` สร้างแบบ lazy เมื่อคำหรือ decision ชัดจริง (silently skip จนกว่าจะถึง)

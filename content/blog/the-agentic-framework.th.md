Agentic Framework คือชุดเครื่องมือที่ทีม T4 สร้างขึ้นเพื่อให้ coding agents เป็น developers หลักของ repo ของพวกเขา:

- **xeno-skills** — skills, hooks บังคับใช้ และมาตรฐานปฏิบัติการ
- **openclink** — MCP server ที่เชื่อมต่อ CLI agents เข้าเป็นเวิร์กโฟลว์เดียว
- **Clone Space** — เว็บ archive ที่อ่านได้โดยเครื่อง ให้ agent ศึกษา

site นี้มีสองหน้าที่: นำเสนอ ecosystem และบันทึกเรื่องราวของมันอย่างใกล้ชิด

**อะไรกำลังมาถึง.** architectural analysis (Antigravity) และ code review (Codex) กำลังดำเนินอยู่ ทั้งคู่จะลงอยู่ใน `docs/` และถูกกลั่นเป็นหน้า ecosystem และ deep-dive posts ฉบับเต็ม จนถึงเวลานั้น หน้า ecosystem ด้านบนคือ stubs ไม่ใช่สรุป

The Agentic Framework is the set of tools the T4 team built to make coding
agents the primary developers of their repos:

- **xeno-skills** — the skills, enforcement hooks, and operating standard.
- **openclink** — the MCP server that connects the CLI agents into one
  workflow.
- **Clone Space** — machine-readable web archives for agents to study.

This site has two jobs: present the ecosystem, and blog it as it evolves.

**What is still arriving.** The architecture analysis (Antigravity) and the
code review (Codex) are in progress; both land in `docs/` and get distilled
into the ecosystem pages and proper deep-dive posts. Until then, the
ecosystem pages above are stubs, not summaries.
